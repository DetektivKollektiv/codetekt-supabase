# Security Policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/DetektivKollektiv/codetekt-supabase/security/advisories/new).
Do not disclose a vulnerability in a public issue or discussion before a fix is
available.

Include the affected component, reproduction steps, impact, and any suggested
mitigation. Do not include credentials or personal data in the report.
